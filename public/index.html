API Endpoints

  • POST /webhook - Webhook endpoint for events
  • GET /agent/security_sweep - Trigger security sweep
  • POST /protect/login - Login to UniFi Protect
  • GET /protect/cameras - Get all cameras (requires API key)
  • GET /protect/cameras/{id} - Get specific camera (requires API key)
  • GET /protect/cameras/{id}/streams - Get camera streams (requires API key)
