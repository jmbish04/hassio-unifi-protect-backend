# Cursor Agent Instructions - UniFi Protect API Worker

## 🎯 Project Context

This is a **backend Cloudflare Worker** that provides an API for UniFi Protect integration. The system uses a four-tier architecture:

```
UniFi Protect Cameras → FastAPI Service → Backend Worker (this) → Frontend Worker → Browser
```

- **FastAPI Service** (`PROTECT_API`): Handles RTSP to HLS conversion, session tokens, and direct UniFi Protect API access
- **Backend Worker** (this worker): Proxies FastAPI endpoints, manages authentication, and provides additional features
- **Frontend Worker** (separate): Consumes backend worker endpoints for live camera streams and UI
- **Browser**: Displays the frontend worker interface

**⚠️ Important**: This is the **backend worker** - frontend workers should connect to this worker's API, not directly to the FastAPI service.

## 🔑 Critical Authentication Pattern

**ALWAYS remember the four-tier authentication system:**

- `PROTECT_API_KEY` → Backend Worker authenticates with FastAPI service (`PROTECT_API`)
- `WORKER_API_KEY` → Frontend Workers authenticate with this Backend Worker
- **Bearer Tokens** → Generated by `/proxy/session/token` for HLS stream access

## 🚨 Common Issues & Quick Fixes

### 1. API Endpoint Errors

- **Problem**: 404 errors on UniFi Protect calls
- **Solution**: Use `/protect/login` NOT `/api/auth/login`
- **Verification**: Check `https://unifi-cameras.hacolby.app/openapi.json`

### 2. Authentication Headers

- **UniFi Protect API**: Uses `x-api-key` header (NOT Bearer token)
- **Worker API**: Uses `x-api-key` header for client requests

### 3. Environment Variables

- **Required**: `PROTECT_API` (FastAPI service URL), `PROTECT_API_KEY`, `WORKER_API_KEY`, `UNIFI_USERNAME`, `UNIFI_PASSWORD`
- **After changes**: Run `wrangler types` to update types

### 4. HLS Streaming Issues

- **Problem**: "Failed to get session token" errors
- **Solution**: Ensure `PROTECT_API` points to FastAPI service, not direct UniFi Protect API
- **Verification**: Test `POST /proxy/session/token` endpoint

### 5. Frontend Worker Integration

- **Problem**: Frontend workers connecting directly to FastAPI service
- **Solution**: Always use this backend worker as the single entry point
- **Verification**: Frontend workers should call this worker's `/proxy/*` endpoints

## 🎥 HLS Video Streaming Implementation

### Architecture Overview

The system provides live camera streaming through a four-tier architecture:

1. **FastAPI Service** (`PROTECT_API`): Converts RTSP streams to HLS format using ffmpeg
2. **Backend Worker** (this worker): Proxies FastAPI endpoints and manages authentication
3. **Frontend Worker** (separate): Consumes backend worker endpoints for live streams
4. **Browser**: Displays live streams using Video.js and HLS.js

### Authentication Flow

1. **Session Token Generation**: Frontend Worker calls `POST /proxy/session/token` with `WORKER_API_KEY`
2. **HLS Proxy Start**: Frontend Worker calls `POST /proxy/hls/{camera_id}/start` to initialize stream
3. **Stream Access**: Frontend Worker uses Bearer token for HLS segment requests

### Frontend Implementation

The frontend automatically:
- Initializes HLS streams for all connected cameras on page load
- Uses Video.js with HLS.js for cross-browser compatibility
- Provides real-time status updates via WebSocket connections
- Handles authentication and error states gracefully

### Stream Display Features

- ✅ **Clickable Camera Grid**: Cards that open full-screen modals
- ✅ **Live Video Streaming**: HLS streams with Video.js and HLS.js support
- ✅ **Real-time Status**: WebSocket connections for live stream status updates
- ✅ **Error Handling**: Comprehensive error handling for stream failures

## 🚀 Frontend Worker Development Guide

### For Frontend Worker Developers

If you're building a frontend worker that consumes this backend worker API:

#### **Base URL Configuration**
```javascript
const BACKEND_WORKER_URL = 'https://your-backend-worker.your-subdomain.workers.dev';
const WORKER_API_KEY = 'your-worker-api-key';
```

#### **Authentication Pattern**
```javascript
const headers = {
  'x-api-key': WORKER_API_KEY,
  'Content-Type': 'application/json'
};
```

#### **HLS Stream Integration Example**
```javascript
// 1. Get session token
const tokenResponse = await fetch(`${BACKEND_WORKER_URL}/proxy/session/token`, {
  method: 'POST',
  headers,
  body: JSON.stringify({ camera_id: 'camera_id' })
});
const { token } = await tokenResponse.json();

// 2. Start HLS proxy
const startResponse = await fetch(`${BACKEND_WORKER_URL}/proxy/hls/${cameraId}/start`, {
  method: 'POST',
  headers,
  body: JSON.stringify({ quality: 'medium' })
});
const { proxy_hls_url } = await startResponse.json();

// 3. Use HLS stream with Video.js
const streamUrl = `${BACKEND_WORKER_URL}${proxy_hls_url}`;
// Configure Video.js with Bearer token authentication
```

#### **Critical Rules**
- ✅ **Always use this backend worker** as your API endpoint
- ❌ **Never connect directly** to the FastAPI service
- ⏰ **Implement token refresh** (tokens expire in 10 minutes)
- 🔐 **Use Bearer tokens** for HLS stream access
